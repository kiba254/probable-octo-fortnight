# Kelvin Kiba — 3-page professional portfolio

A responsive, static website built from the details in `Kelvin_Kiba_Banking_Enhanced_CV.docx`.

## Pages
- `index.html` — homepage, professional summary, focus areas, career direction.
- `about.html` — profile, experience, education, skills, and certifications.
- `projects.html` — project summaries, supplied professional links, and contact details.
- `styles.css` — responsive visual design.
- `script.js` — mobile navigation and current footer year.

## Preview locally
Extract the ZIP, then open `index.html` in a browser. No build tools or server are required.

## Publish online
Upload the extracted files to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Keep the three HTML files, stylesheet, and script in the same directory.

## Before publishing
1. Review all contact details.
2. Add direct repository URLs and screenshots for projects where you have public, working examples.
3. Add a professional photograph if desired (replace the `KK` placeholder in `index.html`).
4. If you want a CV download button, place a public PDF CV in the site folder and link to it.
5. Verify that each public project is accurately described and that no confidential code or data is exposed.

## Accuracy note
The project cards describe projects listed in the CV. They do not claim public demos or repository URLs that were not supplied. The banking/relationship-management direction is presented as a career goal, not previous banking employment.
