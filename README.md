# Kelvin Kiba — Updated Professional Portfolio

Upload every file in this folder to the root of the `kiba254.github.io` GitHub repository.

Files:
- index.html — homepage with Kelvin's photograph as a background
- about.html — profile and skills
- projects.html — projects and guided contact/enquiry form
- styles.css — responsive styling
- script.js — mobile navigation and email/WhatsApp form handling
- kelvin-kiba.jpg — homepage background portrait

The contact form creates a prefilled email draft or WhatsApp message. Visitors must review and send it themselves. This static GitHub Pages site does not store submitted enquiries or send messages in the background.

After uploading, open https://kiba254.github.io/ and refresh. If the old version remains, hard-refresh with Ctrl+F5.
